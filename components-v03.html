Section01

Buttons

Primary action is hairline-black on paper. No drop shadow. No rounded corners. Hover deepens the fill; focus draws a 2px cyan ring at 2px offset. Destructive and signal variants reserve themselves for state, never style.

Use sparinglyOne primary per surface. Group secondary actions left of primary. Never stack three primary buttons in a row.
Primary · Secondary · Ghostbtn / btn.secondary / btn.ghost
Three weights for three roles. Link variant inherits ink, underline-offset 3px.
Sizes.sm / default / .lg
Body type scales with density; buttons scale by variant.
Signal variants.cool / .eco / .warn / .danger
Signal colour is a status claim. Reserve for irreversible or stateful actions.
Icon & FAB.icon / .btn-fab
Square by default. FAB anchored in floating contexts only.
Button group.btn-group
Shared border between siblings; active sibling fills ink.
Statesloading / disabled / with kbd
Loading uses a 12px spinner inverted against the fill.

Section03

Selection controls

Checkbox, radio, switch. All square except the radio (the only circular control in the system). Filled state uses ink; the check mark is paper. No animation other than fill swap and a 120 ms ease.

Switch vs checkboxSwitch implies immediate effect. Checkbox implies stored intent that submits with a form.

Conservatory v0.3

A spatial operating system for urban intelligence. The component kit shown here mirrors the doctrine and primitives in style-guide-v03.html.

Tokens

Density · Room · Mode all operate on the same token tree. Surfaces respect data-mode="dark" by re-mapping --paper-*, not by overriding rules per-component.

This file

Self-contained. Vanilla HTML, vanilla JS, inline SVG. No build step. No external assets. Drop into any static host.
