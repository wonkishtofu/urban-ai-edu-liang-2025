Conservatory — biophilic design system v0.1

Calm interfaces, grown slowly.

A system for software that wants to feel cultivated rather than constructed — legible, professional, and quietly alive. Tuned for mobile, mapping, customer data, and AI surfaces with one shared atmosphere.

01 / Principles

What the system optimizes for

Four commitments that resolve every other design decision. When two principles conflict, the earlier one wins.

Foundation

Legibility before flourish

Type, contrast, and hierarchy are load-bearing. Decoration is allowed only after a screen reads cleanly at arm's length on a sunny day.

Test: read at 75% brightness, outdoor.

Calm density

Dense data without anxiety. Generous spacing around clusters, restrained accents inside them. The eye should be able to rest before it works.

Test: 60s on screen, no tension.

Living surfaces

Motion is slow, organic, and meaningful. Interfaces settle rather than snap. Color shifts hint at state without shouting it.

Test: silence the device — does it still feel responsive?

Professional warmth

The product is being used at work. Tone is competent and steady, but never sterile — warm bronze and serif italics carry the welcome.

Test: would a regulator trust it? Would a designer want it?

06 / Motion

Three curves, slowly

Every animation is named for what it imitates — a leaf settling, a bud opening, a slow breath. Default durations are unusually long (240–420ms) on purpose.

08 / Accessibility

Calm has to be legible

Biophilic palettes drift naturally toward low contrast. The system pushes back: every ink-on-surface pair is checked, and signal colors are never the only carrier of meaning.

Guardrails
  • Body text contrast ≥ 7:1. Mist-900 ink on Mist-50 paper, Canopy-300 ink on Canopy-900 in night mode. AA-Large at minimum, AAA where the type allows.
  • No color-only state. Status pills, signal dots, and map layers all pair color with a label or icon. A screenshot in greyscale should still be readable.
  • Focus is visible and bronze. Keyboard focus uses a 3px Canopy-100 ring at all times — never suppressed. On warm surfaces, the ring shifts to Bronze-200.
  • Motion respects prefers-reduced-motion. Settle/Bloom collapse to instant transitions; Breathe stops. Loading still communicates progress via static text.
  • Type minimum 13px. Mono captions and dense data tables never drop below 12px and only with +1.5 line-height.
