Civic intelligence v0.2 — refined Tropical Civic Futurism

A design language for civic intelligence, not a creative lab.

Conservatory v0.2 reframes biophilic UI as something heavier: an interface system for planning, governance, and ecological operations. Calm where calm earns trust. Disciplined where decisions have consequences. Climate-aware throughout.

Doctrine01

Four commitments. Ordered.

When two principles conflict, the earlier wins. These replace v0.1's softer framing — each commitment now carries an operational test that the user-facing surface has to pass before it ships.

DoctrineCivic operability over visual delight
01 / Authority

Hierarchy is load-bearing

The interface must communicate structure before mood. Panels, nav, and content sit at clearly different perceptual weights — a screenshot at 20% size should still reveal the page's spine.

TestSquint test: can you describe the layout?
02 / Permanence

Built, not floated

Surfaces feel anchored, framed, and engineered. Glow and translucency are rationed. Shadows are hairlines. The system reads like architecture, not concept renders.

TestWill it still feel right in 2040?
03 / Climate

Atmospheric, not decorative

Light, depth, and color shift with state — but slowly, like weather. Motion is climatological: fog, light, airflow. Decoration that doesn't carry information is removed.

TestCould it run for 60s without distracting?
04 / Operability

Reads at every density

The system must function at three working densities: ambient (portals, exploration), operational (dashboards, workflows), dense (tables, GIS, approvals). One DNA, three calibrations.

TestDoes a 14-column table still feel calm?

Any governed surface uses a frame — a 1px outline plus corner ticks at top-left and top-right. The ticks are the system's signature: small, structural, deliberate. Motion07

Climatological, not animated

v0.1's curves were named for plants. v0.2's are named for atmosphere: a puck that settles like a leaf, a fog-pass that crosses a surface without changing its content, a slow light-shift that hints at state without alarm. Decoration that isn't carrying information has been pulled.

Default duration200ms · slower on idle
Curve · 01

Settle

cubic-bezier(.4,0,.2,1) · 200–420ms · default for state changes, layout shifts, dismissals.

Curve · 02

Fog-pass

Linear · 5s+ · slow translucent shimmer across loading or idle surfaces. No spinners.

Curve · 03

Light-shift

ease-in-out · 4s loop · slow tint drift to suggest live state. Used on agent surfaces and live data tiles.

Maps08

A tropical civic cartography

v0.1's map mock leaned on bright pins and a soft green wash — generic enterprise GIS. v0.2 proposes a discrete spatial language: roads as embedded hairlines, transit as luminous veins, greens as translucent ecological strata, terrain as humid-air depth, and labels as institutional cartouches. The map is part of the brand, not a Mapbox default.

DoctrineThe map carries identity, not just data
Layer · 01

Roads — embedded

Hairline strokes in graphite-400, never bright. They scaffold, they don't shout. Major arteries gain a 0.5px halo, not color.

Layer · 02

Transit — luminous veins

Cyan lines with a 2px outer glow. The only place in the system where glow is licensed. Reads as the city's nervous system.

Layer · 03

Ecology — translucent strata

Canopy and parks overlay as 35–50% green washes with hard 1px boundaries. They feel layered onto the city, not painted over it.

Layer · 04

Heat & humidity — atmospheric depth

Surface temperature as bronze washes; terrain elevation as gradient from warm to cool grey. Climate visible without needing a legend at first glance.

Layer · 05

Labels — cartouches

Information panels are cartouches: hard-edged cream rectangles with a corner tick, set against the dark map. They feel placed by a hand, not floated by JavaScript.

Layer · 06

Chrome — dark legend rail

The legend is a graphite-900 panel matching the platform's left rail. Continuity between app shell and map is the strongest signal that "this map is part of this system."

Ritual10

Repetition is trust

A civic system earns trust through consistency — the same gestures, in the same places, at the same speed. v0.2 codifies six rituals. Departures from these rules require an explicit reason recorded in the design system changelog.

Reliability viaProcedural sameness
Ritual · 01

Section heading form

Every major section opens with a s-num (three lines: label, numeral, eyebrow), a left-aligned title, blurb, and right-aligned meta strip. Never a hero image. Never centered.

Ritual · 02

Panel spacing

Card padding follows --pad-card (currently 18px operational). All cards in a region share padding. Never visually different paddings inside one screen.

Ritual · 03

AI response template

Agent name in mono uppercase, then prose, then a citation strip. Every consequential answer carries citations. Citation-less answers must be flagged with a think indicator.

Ritual · 04

Map transitions

Zoom and layer toggles use the fog-pass curve for 420ms. Pins never bounce or pulse on appear — they fade in over 200ms with their cartouche.

Ritual · 05

Approval surfaces

Any destructive or irreversible action uses tier-2 elevation (1.5px ink border), a left rule in signal-critical, and a typed confirmation. No "are you sure?" modals.

Ritual · 06

Time & coordinates

Times in SGT, 24-hour, mono. Coordinates in decimal degrees, 4dp, mono. Dates as YYYY-MM-DD. The system speaks one numerical dialect.

Guard11

Calm must be legible

Civic interfaces serve the public — including users on glare-flooded screens, with low-vision, motion-sensitivity, or working through translation. The atmospheric palette is held to AAA where the type allows, AA-Large at minimum.

TargetsWCAG AAA on body · AA on chrome
  • ContrastBody text contrast ≥ 7:1. Graphite-900 ink on Paper-100 surface. In Night mode, Graphite-100 ink on Graphite-900 surface. Tier-2 framed surfaces use the bold rule to ensure they remain readable on warm backgrounds.
  • Color-onlyNo state communicated by color alone. Status pills always pair color with a typed label. Map layers always have a legend entry. A greyscale screenshot should still be operable.
  • FocusFocus is visible and atmospheric. Keyboard focus uses a 2px Cyan-400 ring on the outside, regardless of mode. Never suppressed. On dark rails, the ring inverts to a 1px white inset.
  • MotionRespects prefers-reduced-motion. Settle collapses to instant. Fog-pass and Light-shift stop entirely. Loading communicates via static think text instead of animation.
  • TypeMinimum 13px body, 12.5px in Dense mode with line-height ≥ 1.5. Mono captions never below 11px. Display weights never used for body. Italics never used for whole paragraphs except editorial leads.
  • MapCartouches are anchored, not floating. Always positioned outside zones of high feature density. Cartouche text contrast checked against the darkest underlying tile, not the average.
